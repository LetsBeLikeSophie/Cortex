# 개인정보 요청 처리 대장

열람·정정·삭제·처리정지 요청을 받을 때마다 한 줄씩 적어요. 앱 안에서 본인이 직접 탈퇴한 것은 적지 않아요(서버 분석 이벤트 `account_deleted`에 남음).

- 기한: 열람 10일(시행령 41조 4항). 삭제 메일 요청 7일(`legal/delete-account.html`).
- 본인 확인: 요청 메일 주소가 계정의 Google 이메일과 같은지, 카카오는 앱에서 보이는 계정 ID를 받아 대조. 확인이 안 되면 처리하지 않고 이유를 회신.
- 이 파일에는 이름·이메일을 적지 않아요. 계정 ID 앞 8자리만 적어요.

| 받은 날 | 요청 종류 | 받은 곳 | 계정 ID(앞 8자리) | 본인 확인 | 처리한 일 | 회신한 날 | 기한 안 |
