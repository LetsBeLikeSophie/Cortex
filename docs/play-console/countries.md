Play Console › 프로덕션(및 각 테스트 트랙) › 국가/지역 › "국가/지역 추가"에서 **전체 선택 후 아래 국가만 해제**해요.
테스트 트랙(내부·비공개)과 프로덕션에 각각 따로 설정해야 해요.

## 확인 사항
- [ ] 출시 직전에 https://www.anthropic.com/supported-countries 를 다시 열어, 출시 국가 중 빠진 곳이 없는지 확인해요(2026-11-12 시행 목록 기준으로 작성함).
- [ ] 개인정보처리방침 8항(국외 이용자)의 제외 국가 문장과 이 목록이 같은지 확인해요.
- [ ] 이용약관 제외 국가 문장(`terms.html` "유럽경제지역(EEA), 영국, 스위스")은 유료 약관을 게시할 때 중국·홍콩·마카오·러시아·벨라루스를 함께 추가해요.
- [ ] 유럽을 열 때: EU·영국 대리인 지정, Anthropic DPA 확인, 동의 문구 점검을 먼저 해요.
